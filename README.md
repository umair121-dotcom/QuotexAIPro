# QUOTEX AI PRO — Android demo starter

This is a minimal Android app shell that can be built into a debug APK.
It is **not** a working AI trading bot.

Current app:
- Opens as a simple demo screen.
- Provides a demo-analysis button.
- Does not capture the screen yet.
- Does not recognize candles or calculate EMA/RSI/MACD.
- Does not generate real BUY/SELL signals or place trades.

Never treat static-screenshot analysis as live tick-flow or guaranteed results.

## Build
Open this project in Android Studio and run `assembleDebug`.
The APK output is `app/build/outputs/apk/debug/app-debug.apk`.
